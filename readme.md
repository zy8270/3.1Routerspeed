# 3.1Routerspeed

华为 / 荣耀系列路由器实时网速可视化面板（Android 客户端）。

通过路由器本地 Web 管理接口登录，读取当前在线设备与实时上下行速率，把「谁在占用带宽」变成一张随手可看的排行榜和曲线图。

> 本项目为个人开发的第三方客户端，与华为、荣耀官方无关。

## 功能

- **路由器登录**：用户名固定为 `admin`，使用路由器挑战应答（SCRAM / PBKDF2-HMAC-SHA256）完成认证，密码不会离开手机。
- **实时网速**：每 3 秒自动刷新一次，展示整机总上传 / 总下载速率。
- **设备排行**：按「本次活跃累计流量」从高到低排列，快速定位当前最占带宽的设备。
- **每台设备详情**：上传 / 下载速率、连接方式（Wi-Fi 频段或有线）、IP、MAC、在线状态、历史累计流量。
- **速度曲线**：路由器整体与单台设备均可展开查看最近 10 分钟的双线（上传 / 下载）速度曲线，并标注峰值。
- **省心登录**：可记住密码并在下次启动时自动登录；会话失效时自动重新登录一次。
- **仅本地保存**：地址与密码只存于本机 SharedPreferences，不上传任何服务器。

## 界面一览

| 登录页 | 设备列表 | 速度曲线 |
| --- | --- | --- |
| 输入路由器地址与管理员密码 | 总速度 + 设备排行卡片 | 最近 10 分钟上下行曲线 |

首页顶部是路由器总速度与设备数量，下面是按活跃度排序的设备卡片；点击卡片展开详情与曲线，点击顶部标题可展开整机曲线。

## 兼容性

- 面向华为 / 荣耀家用路由器的本地 Web 管理接口（`/api/system/user_login_nonce`、`/api/system/user_login_proof`、`/api/system/HostInfo`）。
- 默认网关通常为 `192.168.3.1`，可在登录页手动修改。
- 手机需连接到该路由器的 Wi-Fi（或处于可访问其管理地址的局域网内）。
- 不同型号、不同固件版本的管理接口可能存在差异；若接口不匹配，应用会给出相应错误提示。

## 快速开始

1. 用 Android Studio 打开本项目，等待 Gradle 同步完成。
2. 设备连接路由器 Wi-Fi，运行应用。
3. 填写路由器地址（默认 `192.168.3.1`）与管理员密码，点击「登录并查看设备」。
4. 若勾选「记住密码」，下次启动会自动登录。

也可以直接构建 APK 后安装：

```bash
# Android Studio 中：Build > Build Bundle(s) / APK(s) > Build APK(s)
```

## 项目结构

```
app/src/main/java/com/example/routerspeed/
├── MainActivity.kt      # 登录页、设备列表、设备详情等 Compose 界面
├── RouterViewModel.kt   # 登录状态、自动刷新、状态管理
├── RouterRepository.kt  # 登录握手、设备接口请求与错误处理
├── Scram.kt             # PBKDF2-HMAC-SHA256 挑战应答计算
├── Device.kt            # 设备模型、活跃度累计、速率格式化
└── SpeedChart.kt        # 自绘速度曲线
```

## 数据与隐私

- 应用仅访问局域网内路由器的管理地址，不连接任何第三方服务器。
- 路由器地址与密码保存在本机私有目录；关闭「记住密码」会清除已保存的密码。
- 路由器管理页面使用 HTTP，应用为此开启了明文流量（`usesCleartextTraffic`），请仅在可信的家庭局域网中使用。
